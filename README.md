# Prakhar Srivastava — Portfolio (Frontend Only)

Pure frontend developer portfolio built with **HTML5**, **CSS3 (Tailwind CSS)**, and **Vanilla JavaScript** (`index.html`, `style.css`, `script.js`). No backend required.

## Run on Localhost
- Double-click `index.html` to open in any browser, or run via VS Code Live Server.

## Deploy on Vercel
1. Push this folder to a **GitHub** repository.
2. Go to **Vercel** -> **Add New Project** -> Import your GitHub repository -> Click **Deploy**.
